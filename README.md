# イル企画 Webデザイン案

イル不動産株式会社のサイトデザイン・実装引継ぎ用リポジトリです。

## 確認方法

このフォルダで、次を実行してください。

```bash
python3 -m http.server 4173
```

その後、`http://localhost:4173/` をブラウザで開きます。

## 主なファイル

- `index.html` — トップページ
- `akiya-saisei-kaitori.html` — 空き家再生・買取
- `reason.html` — 選ばれる理由
- `case.html` / `blog.html` — 実例・コラム用の現行デザイン
- `company.html` / `recruit.html` / `faq.html` — 固定ページ案
- `assets/` — 現在のページで使用している画像素材
- `sitemap.md` — サイトマップ案

## 引継ぎメモ

- 現段階は静的HTMLによるデザイン・導線の検証版です。
- 実例・コラムは、将来的に共通のCMSで管理する想定です。
- 空き家コラムはAIで下書きを作成し、イル企画が内容を監修して公開する方針です。
- フォーム送信、CMS、アクセス解析、SEO用の構造化データなどは、本実装フェーズで追加します。
